Upload a PDF, ask anything about its contents, and get an AI-generated answer backed by exact source passages — without sending a single byte to a cloud API.

No cloud LLM API 100% local inference Semantic search (FAISS) Page-level citations Offline-capable

How It Works

Each question triggers a two-stage process: first retrieve the most relevant passages from your PDF, then send them — along with your question — to the local language model.

Installation

Setup Guide

Takes about 5–10 minutes. You only need internet for the initial setup — after that, everything runs offline.

1
Open the project directory
Navigate to wherever you cloned or saved the project.
cmd
cd /d C:\Users\User\OfflineAIAssistant
2
Create and activate a virtual environment
If you already have a working venv, activate it instead.
cmd
python -m venv venv
venv\Scripts\activate.bat
3
Install dependencies
rank-bm25 is only needed if you added the optional BM25 hybrid retrieval code.
cmd
python -m pip install --upgrade pip
pip install streamlit requests pymupdf \
  sentence-transformers faiss-cpu numpy rank-bm25
4
Download the Ollama LLM
If already installed, this command won't re-download. Verify with ollama list.
cmd
ollama pull qwen2.5:1.5b
5
Download the embedding model
Run once while online. The app uses local_files_only=True, so the model must be cached before going offline.
cmd
python -c "from sentence_transformers import SentenceTransformer; \
  SentenceTransformer('sentence-transformers/all-MiniLM-L6-v2'); \
  print('Embedding model ready')"
6
Prepare the default PDF index
Place a text-based PDF at documents/software_engineering.pdf, then build the FAISS index.
cmd
python build_index.py
7
Start Ollama and run the app
Make sure Ollama is running, then launch Streamlit. Open http://localhost:8501 in your browser.
cmd
streamlit run app.py

Usage

Using the App

Browser UI

  1. Open the app at localhost:8501
  2. Keep the default PDF or upload one in the sidebar
  3. Wait for a newly uploaded PDF to index
  4. Type a question and read the answer
  5. Expand View retrieved source passages to verify

Terminal version

A command-line interface is also included for quick queries without a browser.

cmd
python ask_question.py

Type a question when prompted. Enter exit to quit.

Example questions

For a software engineering document, try:

What is cohesion? Explain the Waterfall Model. Disadvantages of the classical Waterfall Model? Function-oriented vs object-oriented design?

Help

Troubleshooting

Check that Ollama is installed and the model is present:

cmd
ollama list

If needed, start Ollama from your installed application or launch the service, then retry.

Rebuild the index:

cmd
python build_index.py

Rebuild using the same chunk_text.py, embedding model, and PDF-processing code that the app uses:

cmd
python build_index.py

Reconnect to the internet and re-run the embedding model download command from the setup section, then test offline again.

The PDF is likely scanned or image-only. OCR processing (e.g. Tesseract via pdf2image + pytesseract) is required before the document can be searched.

Known Issues

Limitations

  • ▲Vector similarity may miss relevant passages; it's a ranking signal, not a guarantee of correctness.
  • ▲Similarity scores are not probabilities — high score doesn't mean the answer is accurate.
  • ▲Page numbers identify the source of retrieved text; they don't independently verify every generated statement.
  • ▲Scanned PDFs require OCR preprocessing.
  • ▲A 1.5B-parameter model may produce incomplete or inaccurate answers on complex questions.
  • ▲Only one PDF can be active at a time.
  • ▲Follow-up questions don't carry conversational context unless memory logic is added.

Privacy & Security

Privacy Notes

🌐

Fully local by default

Ollama serves the model at http://localhost:11434. Embeddings and FAISS run on local files only. No document content leaves your machine during normal operation.

📦

Initial setup requires internet

Packages and model files need to be downloaded once. Normal operation works offline once everything is installed.

⚠

Don't commit sensitive documents

The documents/ folder may contain personal or copyrighted files. Add it to .gitignore before pushing to a public repository.
